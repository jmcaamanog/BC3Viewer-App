## 📖 Descripción

`BC3 Viewer` es una potente aplicación multiplataforma que permite **visualizar, editar, comparar, planificar, analizar el impacto ambiental y exportar** archivos en formato BC3 (estándar FIEBDC-3 utilizado en España para el intercambio de presupuestos de construcción). La aplicación opera con arquitectura **100% cliente offline**, garantizando la privacidad absoluta de los datos de tus proyectos.

## 🛠️ ¿Qué se ha hecho en este repositorio?

1.  **Migración Arquitectónica a Cliente Puro (Offline):**
    *   **Portado del Parser:** Tradujimos el parser original escrito en PHP (`BC3Parser.php`) a JavaScript del lado del cliente (`BC3Parser.js`). Toda la lectura e interpretación de registros (`~V`, `~C`, `~D`, `~M`, `~T`) se ejecuta ahora localmente.
    *   **Lectura de archivos local:** Modificamos `app.js` para usar la API `FileReader` y `TextDecoder` del navegador con detección automática de codificación (ANSI, Windows-1252, UTF-8), eliminando llamadas a servidor externo.
2.  **Integración de Soporte de Escritorio (Windows con Tauri):**
    *   Inicializamos e integramos **Tauri** (`src-tauri/`).
    *   Generación de instaladores `.exe` (NSIS) y `.msi` (WiX) ultra-ligeros.
3.  **Integración de Soporte Móvil (Android con Capacitor):**
    *   Inicializamos **Capacitor** e integramos el soporte de plataforma Android (`android/`).
    *   Sincronización de activos `/www` para funcionamiento 100% offline y paquete nativo `.apk`.
4.  **Optimización Visual y Funcional v2.0:**
    *   Motor de visualización analítica (Sunburst, Sankey, Impacto Ambiental CO₂).
    *   Soporte Multi-Presupuesto con pestañas concurrentes.

## 🚀 Cómo Compilar e Instalar

### Requisitos Iniciales
*   Tener instalado [Node.js](https://nodejs.org/).
*   Ejecutar `npm install` en la raíz del proyecto para descargar las dependencias.

### 💻 Construir para Windows (Tauri)
1.  **Prerrequisitos:** Instalar [Rust](https://rustup.rs/) y *Microsoft C++ Build Tools*.
2.  **Probar en desarrollo:**
    ```bash
    npm run tauri:dev
    ```
3.  **Compilar instalador final:**
    ```bash
    npm run tauri:build
    ```

### 📱 Construir para Android (Capacitor)
1.  **Prerrequisitos:** Instalar [Android Studio](https://developer.android.com/studio) y configurar el SDK de Android.
2.  **Sincronizar cambios web:**
    ```bash
    npx cap sync
    ```
3.  **Abrir en Android Studio:**
    ```bash
    npx cap open android
    ```
